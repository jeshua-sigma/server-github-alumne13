# server-github-alumne13
Fent Cami M7


Part pràctica – Fentcami Bloc 3: Servidor al Núvol amb GitHub
Aquest projecte tracta de crear i configurar un servidor Linux al núvol utilitzant GitHub Codespaces, que és una màquina virtual integrada dins GitHub.
Amb aquest servidor podrem:

Tenir una web pública que tothom pot veure.

Crear una web privada protegida amb usuari i contrasenya.

Accedir-hi de forma remota mitjançant SSH.

Gestionar el projecte amb Git i GitHub, utilitzant control de versions.

L’objectiu és aprendre com es despleguen serveis bàsics en un servidor Linux i com es treballa en un entorn al núvol.

Què és i com funciona Codespaces
El projecte utilitza GitHub Codespaces, que ens proporciona una màquina virtual amb Ubuntu totalment connectada al nostre repositori.

Característiques principals del Codespace
Funciona amb Ubuntu Linux.

Permet utilitzar un terminal complet.

Podem instal·lar serveis com Apache, SSH, etc.

Disposa de reenviament de ports, que ens deixa obrir la web des del navegador.

Està integrat directament amb Git i GitHub.

L’entorn és persistent, així que els canvis queden guardats al repositori.

En resum: podem treballar com si tinguéssim un servidor Linux real, però sense instal·lar res al nostre ordinador.
